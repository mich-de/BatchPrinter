First public release of BatchPrinter, a free batch-printing tool for Windows.

- Print queue for PDFs, images and Office documents, with drag & drop, folders and reordering
- Print preview with "OK, print all" for large queues
- Native PDF rendering (no PDF reader required), full-page printing
- Copies, collate, duplex, page ranges, profiles, 8 themes
- Single instance with "Send to" and right-click integration

Requires Windows 10/11 and .NET Framework 4.8. The executable is not code-signed, so SmartScreen may show a warning. The interface is in Italian.
